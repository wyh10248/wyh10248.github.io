个人介绍

研究简介

我的研究主要围绕生物医学数据中的关联预测问题展开，关注如何利用图神经网络、异构图表示学习、 图 Transformer、矩阵分解和多源特征融合方法，刻画复杂生物实体之间的潜在关系。

目前的工作涉及 lncRNA-disease association、microbe-disease association、 microbe-drug association、gene regulatory network inference 等方向，希望通过可解释、 稳健的计算模型为生物医学发现提供方法支持。

Academic Focus

  • Heterogeneous biological network representation learning
  • Multi-source biomedical feature integration
  • Graph-based association prediction and ranking
  • Single-cell RNA-seq regulatory network inference

Research Interests

研究兴趣

01

Graph Representation Learning

研究图神经网络、图 Transformer、图扩散预训练、动态图学习等方法，用于捕获生物网络中的结构依赖和语义关系。

02

Biomedical Association Prediction

面向疾病、lncRNA、microbe、drug 等实体，构建关联预测模型，挖掘潜在候选关系和高可信生物学线索。

03

Heterogeneous Data Integration

融合相似性网络、功能注释、拓扑结构和多源特征，提升稀疏场景下模型的表示能力与泛化能力。

04

Single-Cell Data Mining

探索 single-cell RNA-seq 数据中的调控信号建模，尤其关注基因调控网络推断和细胞层面的动态关系学习。
